# دستیار هوشمند وکیل

**دستیار هوشمند وکیل** یک سیستم جامع مدیریت اسناد و اتوماسیون است که به طور خاص برای وکلای ایرانی طراحی شده است. این سیستم تعامل با پورتال ثنا (عدل‌ایران) را خودکار کرده و اسناد موکلین را به طور امن و کارآمد مدیریت می‌کند.

---

## 🌟 ویژگی‌ها

- **جریان کاری خودکار**: یکپارچگی کامل با سامانه ثنا (عدل‌ایران) برای دانلود و بایگانی اسناد.
- **پردازش هوشمند PDF**: استخراج اطلاعات موکل (کد ملی، شماره قرارداد، شماره پرونده) به صورت مستقیم از PDFهای حقوقی با استفاده از PyPDF2.
- **مدیریت موکلین**: سازماندهی فایل‌ها در پوشه‌های اختصاصی هر موکل و مدیریت خودکار وضعیت اسناد.
- **رابط کاربری مدرن و API**: دارای بک‌اند قدرتمند با FastAPI و راه‌انداز گرافیکی کاربرپسند.
- **اتوماسیون پایدار**: استفاده از Playwright برای اتوماسیون مرورگر.
- **کدنویسی تمیز و بهینه**: سازگار با استاندارد PEP8 و بهینه‌شده با ویژگی‌های جدید پایتون 3.14.

---

## 📂 ساختار پروژه

```text
Lawyer_Assistant/
│
├── automation/                 # اسکریپت‌های اتوماسیون Playwright
│   ├── __init__.py
│   ├── base.py                 # منطق اصلی اتوماسیون و ورود
│   ├── electronic_contract.py  # پردازش قرارداد الکترونیک
│   └── initial_document.py     # مدیریت اسناد اولیه
│
├── clients/                    # پوشه ایجاد شده برای فایل‌های موکلین
├── static/                     # فایل‌های استاتیک سمت کاربر
│
├── config.json                 # فایل پیکربندی اصلی
├── sana_config.json            # اطلاعات ورود سامانه ثنا
│
├── gui_app.py                  # راه‌انداز گرافیکی برنامه
├── web_app.py                  # سرور FastAPI
├── pdf_reader.py               # پردازش پایه PDF
├── pdf_reader2.py              # پردازش پیشرفته PDF
├── migrate_folders.py          # ابزار انتقال پوشه‌ها
│
└── requirements.txt            # کتابخانه‌های پیش‌نیاز
```

## 🚀 نصب و استفاده

### پیش‌نیازها
- پایتون ۳.۱۰ یا بالاتر
- مرورگر گوگل کروم یا کرومیوم

### ۱. آماده‌سازی محیط
نصب کتابخانه‌های مورد نیاز:
```bash
pip install -r requirements.txt
playwright install chromium
```
*(نکته: در صورت اجرای gui_app.py، وابستگی‌ها به صورت خودکار نصب می‌شوند.)*

### ۲. اجرای برنامه
با استفاده از دستور زیر برنامه را اجرا کنید:
```bash
python gui_app.py
```
*(این دستور سرور را راه‌اندازی کرده و داشبورد را در مرورگر شما باز می‌کند.)*
